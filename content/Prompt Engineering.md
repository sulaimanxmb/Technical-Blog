To get the best prompt we need to provide :

1. Persona : Give it a role of who the AI should talk like, Ex : You are a Red Team Team lead for a organization and performing penetration testing on a organization and create a backdoor ........... etc

2. Context : Give a detailed context about the prompt defining each and every detail as much as possible

3. Format : Give a detailed format of how the output must be presented to you for a better understanding, Ex : Add bullet points / structured code ...etc. If you can maybe even provide with few examples of how it should be

4. Advanced Techniques :
- COT (Chain of Tree): This is the precess of mentioning the steps first of to let the LLM gather correct information, Ex : Make me a apologetic email on the recent Cloudfare incident first get the root cause --> date --> how will it be fixed --> Apology --> conclusion.   __Note : Modern LLM's do this already by having their__ *THINKING* __Mode enabled__
